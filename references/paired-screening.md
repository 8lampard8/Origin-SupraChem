# 配对强度筛选

适用于已经给出空白与两种构型强度的表格。保留每个实验条件、样品行和配对构型，按各自空白计算 `ΔI = I − I₀`。同一条件共用空白时只在原始表记录一次。各样品有自己的实测空白时逐行记录。

- 双向图左侧的条形显示 `|ΔI|`。颜色区分两种构型，实心与斜线分别表示荧光升高与降低。带符号的 `ΔI` 保留在工作表。
- 本图型的 `EF` 定义为较大的 `|ΔI|` 除以较小的 `|ΔI|`。任一响应缺失或较小值为零时，EF 留空。较小响应接近空白时，高 EF 需结合两侧实际响应判断。
- 条形默认采用原单位的线性刻度，各条件共用响应范围及 EF 范围。每个条件单独生成一个可编辑图页。强调样品时可加粗名称并标注该样品的实测增量。

## 合成输入与运行

下面两组数据演示输入结构。条件设置 `blank` 时，每行依次为样品、第一构型强度和第二构型强度。逐行空白的输入在样品后增加一列空白。强度缺失用 `null`。

```json
{
  "unit": "CPS",
  "pair_labels": ["L", "D"],
  "highlight": ["Guest A"],
  "conditions": [
    {
      "name": "System A",
      "blank": 100,
      "rows": [["Guest A", 145, 235], ["Guest B", 80, 110]]
    },
    {
      "name": "System B",
      "rows": [["Guest A", 120, 250, 400], ["Guest B", 115, 115, 160]]
    }
  ]
}
```

```powershell
python scripts/run_origin.py --script scripts/paired_screening.py --work "work/paired" -- "C:/work/screening.json" "C:/work/screening.opju" --png-dir "C:/work/figures"
```

输出项目包含每组的原始读数表、联动计算表及原生双图层条形图。`--png-dir` 可按需要指定。项目重开时检查计算列及图层数量，导出后再查看图像，确认单位、条件标题、构型、零点和标签位置。较长的样品名与测量标签可在 Origin 中调整。

## 扩展原生图表

跨工作表联动时，用 `csetvalue` 的前置脚本声明原始列范围并设 `recalculate:=auto`。共用空白用该范围第一格，逐行空白用对应数据范围。把升高量和降低幅度分成独立列，可以用相同的实际强度单位绘制两种填充。

原生横向条形使用 `add_plot(..., type=215)` 和 `layer.exchangexy=1`。交换后用 X 轴控制类别顺序，并对左图层反向设置 Y 轴范围，使响应和 EF 在中心零点相接。用 `layer.y2.label.pt` 控制顶部原生刻度的字号；类别间虚线放在半整数行边界。设置链接的数据标签格式时，LabTalk `set` 的 `-j -qms` 可保留运行时的 `$(Y)`，并随数值更新。更换强调样品或改变响应符号后，复核标签所选的条形序列。
