# 后续绘图时更新技能

当任务中出现经过验证的新方法、复现并修复的问题、重复使用的逻辑，或用户明确提出可长期沿用的绘图偏好时，在完成当次结果后更新本技能。一次性样品名、峰值、路径和未验证猜测不写成规则。

1. 识别最小可复用改动，优先修正已有说明，不堆积重复条款。
2. 方法说明归入对应 references；重复代码归入 scripts；仅核心路由或约束放 SKILL.md。
3. 改脚本时以合成数据补充有意义的回归测试。若涉及 Origin 原生函数或布局，在独立实例和工作区测试，再检查导出图。
4. 更新版本记录，说明问题、最终行为和验证范围。
5. 同步当前安装技能与已知本地开源 checkout；有本地差异时先比较并合并，不覆盖用户编辑。可读取安装目录可选 `.maintenance.json` 中的本地 checkout 定位信息；该文件是本机配置，不提交或打包到公开发布。
6. 完成作图时简短说明本次技能更新。如果没有实质可复用改进，不为了更新而改动。
7. 公开 push/PR 只在当前会话明确要求发布或有明确持续发布授权时执行；“后续补充技能”默认是维护本地安装及 checkout。发布前检查差异和将上传的文件；不上传真实实验数据、OPJ/OPJU、图像结果、身份信息、凭据、个人绝对路径或未获授权的项目内容。

检查：`python -m unittest discover -s tests -v`。可用时运行 skill-creator 的 quick_validate，并在 Windows 以 `python -X utf8` 调用。
